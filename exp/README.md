# 实验 3 纯汇编版

目标文件：`garbage_sorter.asm`

实现的基本功能：

- 4 个垃圾桶容量显示在 4 位数码管上，初值为 0-9 伪随机数。
- 按 `F1/F2/F3/F4` 分别选择 4 类垃圾桶开盖。
- 容量为 0 时蜂鸣器响 1 秒，对应数码管显示 `F`。
- 开盖后同一功能键再次按下表示投递 1 袋，容量减 1。
- 开盖后按数字键 `1-9`，立即一次投入对应袋数。
- 开盖后未按数字时，按 `F5` 投入 1 袋。
- 若一次投入数量超过当前剩余容量，蜂鸣器响 1 秒，对应数码管显示 `E`，容量不变。
- 开盖 8 秒自动关闭，KINT 可提前关闭。
- D1-D8 显示开盖剩余时间进度条。

## 键盘定义

按原理图：

```text
K0-K9   -> 数字 0-9
K10-K15 -> F1-F6
```

本程序使用：

```text
F1 -> 桶 1
F2 -> 桶 2
F3 -> 桶 3
F4 -> 桶 4
F5 -> 投入 1 袋
F6 -> 四个桶容量全部置为 9
```

功能键线路对应：

```text
P2.2 + P2.6 -> K10 -> F1
P2.3 + P2.6 -> K11 -> F2
P2.0 + P2.7 -> K12 -> F3
P2.1 + P2.7 -> K13 -> F4
P2.2 + P2.7 -> K14 -> F5
P2.3 + P2.7 -> K15 -> F6
```

## 编译

```sh
cd exp
make
```

输出：

```text
exp/garbage_sorter.hex
```

## 烧录

先在仓库根目录检测调试器：

```sh
make detect
```

然后烧录：

```sh
cd exp
SERIAL=你的调试器序列号 make flash
```
